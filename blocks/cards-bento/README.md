# cards-bento

Custom **cards** block. Purpose: Bento grid of linked tiles with one large featured tile.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: tile image (the first row is the featured tile); cell 2 (optional): label and/or link. One link makes the whole tile clickable.

## Supported variations

No variations.
