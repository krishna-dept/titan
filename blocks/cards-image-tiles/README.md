# cards-image-tiles

Custom **cards** block. Purpose: Grid of linked image tiles (him/her, collections, brands).

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: tile image; cell 2 (optional): label and/or link. One link makes the whole tile clickable.

## Supported variations

No variations.
