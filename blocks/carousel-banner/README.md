# carousel-banner

Custom **carousel** block. Purpose: Container-width promotional banner slider.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: banner image (optional second image = mobile image); cell 2 (optional): link to the promotion (bare URL or labelled link; the whole banner links). Any other text is shown as a caption.

## Supported variations

No variations.
