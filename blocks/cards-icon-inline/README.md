# cards-icon-inline

Custom **cards** block. Purpose: Row of benefit items with a small icon beside a title and one line of text.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: icon or small image; cell 2: title (bold or heading) and a short line; an optional link makes the whole item clickable.
