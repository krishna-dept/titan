# hero-strip

Custom **hero** block. Purpose: Short full-width promotional strip with text and a CTA over a background image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: a background image (own row/cell or with the text; optional second image = mobile background), a short line of text and a CTA link (rendered as a button).

No variations.
