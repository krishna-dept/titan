# carousel-shorts

Custom **carousel** block. Purpose: Slider of vertical video shorts (customer stories, brand videos).

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: poster image; cell 2: link to the video (mp4/webm file, YouTube or Vimeo URL); optional text such as a view count, and an optional "Shop now" product link.
