# carousel-reviews

Custom **carousel** block. Purpose: Customer review / testimonial slider.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per review; lines may be in any cells/order and are recognised by content: rating ("4.5", "4.5/5" or stars), date (e.g. "20 Nov, 2025"), reviewer name (bold or heading line, or a short first line), optional avatar image, and the review text.

## Supported variations

No variations.
