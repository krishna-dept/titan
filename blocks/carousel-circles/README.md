# carousel-circles

Custom **carousel** block. Purpose: Category shortcut slider with circular images and labels.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: image (cropped to a circle); cell 2: label link (or label text plus a link). One link makes the whole item clickable.

No variations.
