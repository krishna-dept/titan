# carousel-hero

Custom **carousel** block. Purpose: Homepage hero slider of full-width linked promotional slides.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: slide image (optional second image in the same cell = mobile image); cell 2 (optional): a short label and/or a link (the label is shown in the indicator strip and the whole slide links), or a heading, description and CTA links which are shown as an overlay.

## Supported variations

No variations.
